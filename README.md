## 🚀 Featured Projects

### 🏥 [NHS A&E Wait Time Analysis](https://github.com/RidhimaGupta4/NHS-AE-Analysis)
> Investigating performance patterns and pressures in England's emergency care system

Analysed NHS A&E attendance and wait time data to uncover patterns in service pressure, seasonal demand, and performance against the 4-hour target. Involves data cleaning, time-series exploration, and visual communication of findings relevant to healthcare policy.

**Tech:** `Python` · `Pandas` · `Matplotlib` · `Seaborn` · `Jupyter Notebook`

---

### 🧪 [A/B Testing Case Study](https://github.com/RidhimaGupta4/AB-Testing-Case-Study)
> Rigorous experimentation framework with statistical hypothesis testing

End-to-end A/B testing pipeline covering experimental design, power analysis, hypothesis testing (t-tests, chi-squared), and interpretation of results — with a focus on avoiding common pitfalls like p-hacking and peeking.

**Tech:** `Python` · `SciPy` · `Statsmodels` · `Pandas` · `Jupyter Notebook`

---

### 🧠 [FPL Predictor](https://github.com/RidhimaGupta4/FPL_Predictor)
> Predicting Fantasy Premier League player scores using machine learning

End-to-end ML pipeline to predict FPL player performance across gameweeks. Involves EDA, feature engineering on player statistics across multiple seasons, and comparison of ML approaches.

**Tech:** `Python` · `Scikit-learn` · `Pandas` · `Matplotlib` · `Jupyter Notebook`

---

### 🛍️ [Croma Web Scraping & Power BI Dashboard](https://github.com/RidhimaGupta4/Selenium-Mini-Project)
> Automated data extraction + interactive visualisation pipeline

Scraped thousands of product listings from Croma using Selenium, cleaned the data with Pandas, and built an interactive Power BI dashboard with price distributions, category breakdowns, and product-level drill-through.

**Tech:** `Python` · `Selenium` · `Pandas` · `Power BI` · `ChromeDriver`
